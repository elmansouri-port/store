Rainbow begleitet Sie auf Smartphone und Tablet

Bleiben Sie erreichbar und mit Ihren Teams verbunden, wo auch immer Sie sind – mit dem gleichen Rainbow-Erlebnis auf iOS und Android.

Im App Store herunterladen (iOS) Bei Google Play herunterladen (Android)

So installieren Sie Rainbow in 3 Schritten

1

Laden Sie das Installationsprogramm herunter

Wählen Sie oben die für Ihr Betriebssystem passende Version aus, unter Windows standardmäßig die 64-Bit-Version.

2

Starten Sie die Installation

Führen Sie die heruntergeladene Datei aus und folgen Sie dem Installationsassistenten: Es ist keine technische Konfiguration erforderlich.

3

Melden Sie sich an

Öffnen Sie Rainbow, melden Sie sich mit Ihren Zugangsdaten an oder erstellen Sie ein kostenloses Konto, um zu starten.

Fragen zur Installation von Rainbow

Ja, der Download und die Installation der Rainbow App sind auf allen Geräten kostenlos. Nach der Installation benötigen Sie ein Rainbow-Konto, um sich anzumelden.

Fast alle aktuellen Computer laufen mit 64-Bit, deshalb ist dies die standardmäßig empfohlene Version. Die 32-Bit-Version ist älteren oder speziellen Konfigurationen vorbehalten.

Rainbow aktualisiert sich automatisch, sobald eine neue Version verfügbar ist. Sie können jederzeit auch das neueste Installationsprogramm von dieser Seite herunterladen.

Ja. Sobald die App installiert ist, melden Sie sich mit Ihren Rainbow-Zugangsdaten an oder erstellen Sie ein kostenloses Konto, falls Sie noch keines haben.

Ja, für Unternehmensbereitstellungen steht ein .msi-Installationspaket zur Verfügung, einschließlich eines LDAP-Connectors zur Synchronisierung Ihrer bestehenden Verzeichnisse.
